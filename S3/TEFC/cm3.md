
## L'ecetend brut d'exploitation (EBE)

```
Excédent brut d'exploitation = Valeur ajoutée
                           (+) Subventions d'exploitation
                           (-) Subventions d'exploitation
                           (-) Subventions d'exploitation

```


Charges de personnel
```
Charges de personnel = Traitement et salaires
                   (+) Charges sociales
```

## Le résultat d'exploitation

```
Résultat d'exploitation = Excédent d'exploitation
                      (+) Reprise sur amortissements, provisions et dépréciations
                      (+) Autres produits
                      (-) Dotations aux amortissements, provisons et dépréiations
                      (-) Autres charges
```
## Le résultat courant avant impot (RCAI)

Il prend en compte les éléments financiers

```
RCAI = Résultat d'exploitation
 (+/-) Quote-par de résultat sur opération en commun
   (+) Produits financiers
   (-) Charges financières
```
