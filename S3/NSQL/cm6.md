# Data Engineer 101

**Data Lake**  :
C'est une architechture d'entreprise, le stockage qui à la responsabilité de contenir une copie de tout les métier s'appelle un *Data Lake* (stockage distribué).

**Date Warehouse** :
Les data engineer créers des bases de données relationnelles à partir du datalake en spark pour une explotation par le métier par les data analyst. Ces bases de données constituent un *Data Warehouse*. C'est en fait une vue sur le *Data Lake*.
