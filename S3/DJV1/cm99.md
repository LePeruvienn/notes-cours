# Données de configuration

## À quoi ça sert ?

Stocker des données statiques !

On peut les stocker en tant qu'asset puis ensuite les passer dans les script afin de consulter les données.

C'est un peu le JSON d'Unity ou l'ont peut d'abord définir un type de JSON avec quelles données on va stocker dedans, pour ensuite pouvoir créer des jeux de données de celui-ci.


## Comment créer un scriptable objet ?

1. Créer une classe qui hérite de `ScriptableObject`

2. Puis ajouter juste au desssus de la définition de la classe, un moyen de pouvoir en créer.

3. Ajouter les propriété que vous voulez !

```cs
[CreateAssetMenu(fileName = "EnemyData", menuName = "Survivor Generate EnemyData", order = 1)]
public class EnemyData : ScriptableObject
{
    private int health,
    ....
}
```

4. Uitlisez les!
